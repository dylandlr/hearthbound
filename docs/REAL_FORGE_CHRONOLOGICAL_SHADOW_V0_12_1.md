# Hearthbound v0.12.1 — Chronological real-Forge receipt audit

This milestone follows the **simulator-only** causal attention experiment in PR #141. It is the first live-evidence integration bridge, but it performs **offline audit**, not neural control or a comparative learning trial.

## Input
The dedicated Forge server's validated `real-perception-validated.json` generated by `validate_live_perception_receipts.py`, containing real `PERCEPTION_RECEIPT` entries from the operator-registered source watcher. All receipt rows must retain the original dimension, source position, observer UUID, server tick, revision, measured wheat, and source state. Unverified arbitrary output is not accepted as valid evidence.

## Replay contract
- Read-only: no socket, RCON, Minecraft connection, commands or executor permissions.
- Strictly chronological: reject any backwards timestamp and enforce monotonic contiguous revisions and change-only receipts for each observer/source.
- For each event, `before_receipt` contains only the same citizen's earlier events, never the new observation, other citizens' state, or an unobserved alternative source.
- `observed` is recorded separately and only becomes available in `after_receipt`.
- Unknown prior state stays UNKNOWN; age comes only from existing receipt timestamps.
- The output has an explicit `counterfactual_reward_available=false` flag for each row. The audit does not pretend to know what would have happened if the agent observed a different chest.
- No learned policy is trained or deployed by this replay; `minecraft_execution_authorized=false` and `training_performed=false` are mandatory.
- Output is a deterministic, SHA-256-addressed JSON artifact, `real-forge-shadow-timeline.json`.

## Verification
Standalone unit fixtures ensure determinism, chronological safety, individual observer separation, missing event denial, integrity checks, and no task authority. Both existing SCRIPTED and TRAINED_MLP Minecraft dedicated-server CI arms run the replay against the **actual** 3-transition wheat receipt chain after validating it.

## Limitations
These receipts represent only registered and successfully observed sources, not all selectable candidate resources. A real neural attention comparison would require logging the actual action-choice candidate set, physical availability, and decision timestamps before a choice. This tool deliberately does not produce counterfactual rewards or claim learned advantages in Minecraft. It is a causality/safety foundation for that experiment.
