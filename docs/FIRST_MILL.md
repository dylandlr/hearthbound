# First Mill — Actual Minecraft Acceptance Specification

## Required environment
Select and lock a reproducible Minecraft 1.20.1 Forge/NeoForge + Create version matrix before compiling. Store exact dependency coordinates/hashes and Java/toolchain version. Never commit downloaded third-party mod JARs absent redistribution permission.

## Vertical slice
1. Boot a real Minecraft dev client and server.
2. Found a colony and observe a persistent named Sable entity with visible navigation.
3. Build a **working real Create millstone**, shaft, and powered source using legitimate Minecraft blocks.
4. Register real input/output containers. Deposit real wheat.
5. Demonstrate operating procedure with player proximity and actual successful production.
6. Switch Sable into autonomous work and see her path, fetch, operate and deliver real inventory.
7. Block output, inspect a clear fault, free capacity and observe resumption.
8. Restart server during a task; confirm recovery and no duplication.
9. Change the policy backend while preserving common actions and verification.
10. Repeat on a two-player server; measure tick rate and action latency.

## Provenance
Earlier runtime logs document a previous experimental implementation with successful deliveries, expertise growth and safe cargo recovery, but the source/JAR is not currently available in this repository. Reimplement and reverify instead of assuming that code exists.

## Evidence standards
Real gameplay footage requires actual screen capture from a running Minecraft client. Clearly identify the modpack version, tested commit, captured build, and active policy. Headless simulation, staging datapacks, concept illustrations, video renders and browser prototypes **do not** satisfy this acceptance test.
