# Hearthbound

A Minecraft-first, fun-first Create-powered AI colony simulator.

Design-first development. See docs/ for the architecture and experiments.

- [Restart-fenced pickup beliefs (v0.16.6)](docs/RESTART_FENCED_BELIEFS_V0_16_6.md)
- [Emergent society and multiplayer readiness roadmap](docs/SOCIETY_AND_MULTIPLAYER_ROADMAP.md)
- [Install a development candidate](docs/INSTALL_DEV_JAR.md)

Current physical recovery trials are operator-triggered. Autonomous societies,
crash-atomic item transfers, and a player-ready multiplayer release are not yet verified.

## Multiagent evaluation reference

For collaboration, social emergence, and strategic evaluation work, see [development research guidance](AGENTS.md) and the [PA4/MARBLE implementation contract](docs/PA4_MARBLE_IMPLEMENTATION_CONTRACT_V0_2.md). The standalone [collaboration scorer](experiments/marble-collaboration-bench.js) and [matched-world evaluation](experiments/collaboration-evaluation-v0-2.js) are research-only, and do not represent validated learned society behavior in Minecraft.
